# Applied projects

Six projects (V4 §7), in Apply → Projects. Each follows one chain: **question → data provenance → assumptions → method → calculation (graded Python, each with a no-code path) → interpretation → decision → limitations**. Data: `src/data/projects/index.js`; graded steps: `src/data/python/projectExercises.js`; data modules generated by `scripts/datasets/build_project_data.py` from the source files below. The three V3.1 projects (Anscombe's quartet, screening, PCA) remain under "More projects".

## No-code path

Every coding step (here and in Code exercises) has a "Not coding yet? Read the result instead" option: the reference solution's printed output and a question about what it means, with an explanation. These answers are **not** recorded as Python evidence (`src/features/practice/CodeExercise.jsx`). 26 no-code outputs are verified by `verify:python`.

## Measuring application (V4 §7) — this learner only

My Progress → Overview → *Your learning signals* (`src/lib/learningSignals.js`, tests in `learningSignals.test.js`). All computed on the device from the learner's own records; nothing is sent anywhere; no population claims.

| Signal | Definition as implemented | Shown when |
|---|---|---|
| Practice success | correct first attempts ÷ attempts in practice, review, mixed practice and checkpoints, by recorded difficulty (a hint before answering records level 1) | ≥ 5 answers |
| Application completion | projects with every step done ÷ projects with at least one step done | ≥ 1 project started |
| Unassisted transfer | transfer items answered correctly **without** a hint ÷ transfer items attempted; counted only from records that note hint use (written since V4) | ≥ 5 answers |
| 14-day retention | per skill, take the first answer given 14 or more days after the learner first got that skill right: skills where that answer was correct ÷ skills that have such an answer | ≥ 5 skills |

No baseline values or effectiveness percentages are claimed for the app.
