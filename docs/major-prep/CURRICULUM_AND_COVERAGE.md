# Curriculum and coverage — Ohlone objectives to lessons

Generated by `npm run docs:college` from the catalog, the lesson bodies and `src/data/college/studyAlignment.js` — edit those, not this file.

**Three different things, reported separately (V5.1 §10):** *coverage* (what this site teaches), *learner mastery* (computed per learner on the device — no population data exist), and *college credit* (never awarded by this site).

**Honest summary.** 35 lessons are written in all, every one an **AI draft awaiting independent human math review (0 human-reviewed)**. Coverage below is counted per catalog topic: a topic counts as *explained* when at least one written lesson teaches it — one lesson is an introduction, not a semester. The “planned” column shows how much of each mapped unit is still only a title. No Ohlone course is fully covered.
